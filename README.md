# Пользователи

Приложение на React и TypeScript. Список пользователей и данные выбранного пользователя загружаются через fetch и useEffect.
Слева отображаются имена, справа — аватар, город, компания и должность.
При быстрой смене выбора предыдущий запрос отменяется.

Для запуска:

```bash
npm install
npm run dev
```

Откройте адрес из терминала. Для загрузки данных нужен интернет.
